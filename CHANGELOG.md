# Luksave Changelog

## [1.3.0] - 2026-05-03
### Added
- Full push notification system (send to individual, team, or everyone)
- Read tracking — see who has opened each message
- Team member status (who has the app installed)
- Clear target selection (worker or team)
- Info bar showing current target
- Improved history table with search and sorting
- Better notification display (system + in-app)

### Improved
- Notification reliability and delivery
- UI/UX in the Comms Dashboard
- Overall stability and performance

### Fixed
- Token handling issues
- Clearing of selections when switching targets
- Read reporting on notification tap

## [1.2.0] - Previous version
- Basic push notifications
- Worker and team selection
- History log
- FCM token management
- New "Forgot Credentials" handling
- Information Screen now handles live location nearby places (Bank, Supermarkets, Food outlets)
- HAP ID information and eMedical feedback added to Home Screen
- Improvements to core engine (DataModels, EmpowerViewModel)
- Overall stability, performance and security improvements

## [1.0.0] - Initial release
- Core worker app functionality
